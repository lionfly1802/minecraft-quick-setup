Lưu ý Legacy Launcher: Website chính thức từng thông báo tạm dừng lượt tải do khiếu nại từ Mojang. Nút tải sẽ mở website chính thức để xem tình trạng mới nhất. Đừng tải file từ trang lạ nhé.

1. Cài CurseForge lần đầu

  1. Mở file cài đặt CurseForge vừa tải.
  2. Nếu Windows hỏi quyền cài đặt, kiểm tra file được tải từ trang chính thức rồi chọn Yes.
  3. Khi được hỏi muốn quản lý game nào, chọn Minecraft.
  4. Nếu hiện lựa chọn kiểu cài đặt, chọn Standard.
  5. Nếu có lựa chọn launcher, chọn Launcher with Mojang / Minecraft Launcher nếu đúng là lựa chọn hiện trên máy bạn. Nếu không thấy, cứ chọn mặc định CurseForge đề xuất.
  6. Chờ cài xong rồi mở CurseForge.
  7. Chọn Minecraft. Nếu ứng dụng yêu cầu thiết lập game hoặc cài thành phần hỗ trợ, bấm Install / Set up và làm theo hướng dẫn trên màn hình.

Màn hình có thể thay đổi theo phiên bản CurseForge. Đừng xóa hoặc ghi đè thư mục Minecraft cũ nếu chưa sao lưu.

2. Cài Legacy Launcher

  1. Mở website Legacy Launcher bằng nút tải phía trên.
  2. Chọn bản dành cho hệ điều hành của bạn nếu website có cung cấp.
  3. Mở file vừa tải và làm theo trình cài đặt.
  4. Mở Legacy Launcher, chọn ngôn ngữ nếu được hỏi và đăng nhập bằng tài khoản Minecraft hợp lệ.
  5. Chưa cần cài Forge hay mod ở bước này.
Nếu trang chính thức vẫn tạm dừng tải, hãy chờ thông báo chính thức. Không lấy file cài từ link lạ.

3. Kiểm tra Java bằng lệnh

Không cần tải công cụ riêng. Dùng cửa sổ lệnh có sẵn trên máy nhé.

🪟 Windows

  1. Nhấn phím Windows, gõ cmd, mở Command Prompt.
  2. Nhập lệnh này rồi nhấn Enter:
java -version

Nếu đã có Java, bạn sẽ thấy thông tin phiên bản. Ví dụ 17.0.x nghĩa là Java 17 được nhận diện. Nếu thấy 'java' is not recognized, máy chưa tìm thấy Java trong PATH (có thể chưa cài hoặc chưa cấu hình).

🍎 macOS

  1. Nhấn Command + Space, gõ Terminal rồi mở ứng dụng.
  2. Nhập lệnh và nhấn Enter:
java -version

Nếu đã có Java, Terminal hiện số phiên bản, ví dụ 17.0.x. Nếu máy báo không tìm thấy Java hoặc yêu cầu cài đặt, Java phù hợp chưa sẵn sàng.

Với Minecraft 1.20.1 Forge: thường dùng Java 17 (64-bit). Nếu modpack yêu cầu phiên bản khác thì làm theo yêu cầu của modpack.

☕ TẢI JAVA 17 — ECLIPSE TEMURIN

Chọn Java 17, hệ điều hành và kiến trúc đúng với máy (thường là x64; Mac Apple Silicon thường là ARM64). Nếu launcher đã tự quản lý Java và game chạy tốt thì không cần cài thêm.

4. Nhập modpack bạn bè gửi vào CurseForge

  1. Mở CurseForge, chọn Minecraft.
  2. Tìm nút Import ở trang Minecraft hoặc khu vực tạo hồ sơ.
  3. Chọn file ZIP modpack mà bạn bè gửi. Nếu nhận link chia sẻ, mở link và làm theo hướng dẫn CurseForge.
  4. Chờ CurseForge tải mod và tạo hồ sơ. Đừng giải nén ZIP rồi kéo tất cả file vào thư mục mods.
  5. Mở hồ sơ, kiểm tra phiên bản Minecraft và mod loader, ví dụ 1.20.1 – Forge.
  6. Bấm Play ngay trong CurseForge để chạy thử trước.

Cách Import áp dụng với file ZIP xuất theo định dạng CurseForge. Nếu chỉ nhận thư mục mods rời thì cách cài sẽ khác.

Trung tâm hướng dẫn CurseForge

5. Dùng modpack đó bằng Legacy Launcher

  1. Trong CurseForge, tìm modpack vừa cài.
  2. Bấm dấu ba chấm (⋮) trên hồ sơ modpack rồi chọn Open Folder.
  3. Mở Legacy Launcher, vào cài đặt phiên bản/hồ sơ Minecraft bạn định chạy.
  4. Tìm mục Game directory / Thư mục game nếu launcher có hỗ trợ.
  5. Chọn đúng thư mục vừa mở ở bước 2. Không chọn thư mục mods con bên trong và không chọn thư mục chung Instances.
  6. Chọn đúng phiên bản Minecraft và Forge giống modpack rồi lưu lại.
  7. Chạy thử. Nếu thiếu thư viện hoặc không nhận mod, mở lại modpack trong CurseForge để xác nhận nó vẫn chạy bình thường.
Lưu ý: Các bản Legacy Launcher có thể khác nhau; không phải bản nào cũng cho đổi Game directory. Nếu không có mục này, đừng tự di chuyển hay chép đè file. Hãy chạy modpack trực tiếp bằng CurseForge.

6. Chơi chung qua mạng ảo

🪟 Nếu bạn là máy chủ (người mở map) — Radmin VPN

  1. Cài và mở Radmin VPN.
  2. Chọn Network → Create Network.
  3. Đặt tên mạng và mật khẩu, rồi gửi cho bạn bè.
  4. Vào thế giới Minecraft, nhấn Esc → Open to LAN → Start LAN World.
  5. Ghi lại cổng LAN hiện trong chat. Gửi IP Radmin VPN cùng cổng đó cho bạn bè.

🪟 Nếu bạn là máy khách (người tham gia) — Radmin VPN

  1. Mở Radmin VPN, chọn Network → Join Network.
  2. Nhập tên mạng và mật khẩu máy chủ gửi.
  3. Tìm IP Radmin của máy chủ (thường dạng 26.x.x.x).
  4. Vào Minecraft → Multiplayer → Direct Connection.
  5. Nhập IP-máy-chủ:cổng-LAN, ví dụ 26.x.x.x:54321 (thay bằng thông tin thật), rồi Join Server.

🍎 Nếu bạn dùng Mac — thử Hamachi

Radmin VPN không có ứng dụng macOS chính thức. Bạn có thể kiểm tra Hamachi tại website của hãng:

Tải Hamachi

Kiểm tra yêu cầu macOS trên trang tải vì hỗ trợ có thể tùy phiên bản. Khi cả nhóm đã vào cùng mạng ảo, máy chủ vẫn mở LAN và gửi IP cùng cổng LAN cho người tham gia.

Nhớ nha: Mọi người cần cùng phiên bản Minecraft, mod loader và bộ mod tương thích. Chỉ chia sẻ mật khẩu VPN với người bạn tin tưởng. Nếu không kết nối được, kiểm tra quyền Java/Minecraft trong tường lửa thay vì tắt toàn bộ tường lửa.
Trang hướng dẫn do người chơi tạo, không phải sản phẩm chính thức của Mojang, Microsoft, Legacy Launcher, CurseForge, Radmin hay LogMeIn. Tải phần mềm từ website chính thức nha.
